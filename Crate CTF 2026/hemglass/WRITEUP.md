# Hemglass speldosa

- **Category:** Misc / OSINT / Audio
- **Target:** `http://hemglass.challs.crate.nu/`
- **Theme:** *"A familiar sound echoes between the villas, suddenly it's just ice cream you can think of."* (the Swedish **Hemglass** ice-cream-truck jingle)
- **Flag:** `cratectf{sm4aRRigt_med_glass}`

## Challenge
A C64-style "music box" (`MELODIPROGRAM V1.0`, `READY.`). You type a melody in the notation
`<length><note><octave>` (e.g. `4C4`, `2.G4`) and press RUN. The melody text is POSTed to
`/verify`, which returns `{ok, flag?, message?}` — the flag only for the **correct Hemglass jingle**.
No oracle feedback (just *"Det där lät inte riktigt som glassbilen…"*), so you must know the tune.

Client files: [`app.js`](app.js), [`synth.js`](synth.js).

## Solution
1. The jingle was historically generated by the **SID 6581** sound chip (Commodore 64) — matching
   the challenge's C64 aesthetic.
2. Swedish Wikipedia cites *"Hemglassmelodin – en rekonstruktion"* (Svenska Commodoreklubben),
   whose source archives (dated right before the CTF) contain the exact note data.
3. The well-tuned PAL C64 reconstruction ([`main_c64.asm`](main_c64.asm)) spells out the melody with
   note names **and** durations:

   | # | Note | Length | | # | Note | Length |
   |---|------|--------|---|---|------|--------|
   | 1 | D4 | quarter | | 9 | B4 | quarter |
   | 2 | B4 | quarter | | 10 | G4 | half |
   | 3 | D5 | quarter | | 11 | D4 | quarter |
   | 4 | B4 | quarter | | 12 | C5 | half |
   | 5 | G4 | half | | 13 | C5 | quarter |
   | 6 | D4 | quarter | | 14 | A4 | half |
   | 7 | B4 | quarter | | 15 | A4 | quarter |
   | 8 | D5 | quarter | | 16 | G4 | dotted half |

4. The winning encoding mapped the reconstruction's relative rhythm to **eighth / quarter /
   dotted-quarter** (SHORT→`8`, LONG→`4`, VLONG→`4.`):

```
8D4 8B4 8D5 8B4 4G4 8D4 8B4 8D5 8B4 4G4 8D4 4C5 8C5 4A4 8A4 4.G4
```

Submitting that to `/verify` returned the flag.
