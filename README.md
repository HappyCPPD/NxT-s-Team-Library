# CTF solved-challenge archive

Writeups and final solve scripts for challenges I solved. One directory per event.

Per challenge: the writeup, the final solve script, and the challenge's own
metadata/source files. Scratch work, brute-force iterations and intermediate
dumps are deliberately not included.
