# Diceware

Remember when we used [dice and dictionaries to generate passwords](https://www.eff.org/dice)?
Well, no-one owns physical dictionaries anymore, and looking up words online would leak your precious passwords.
Cryptography to the rescue: I've built a prototype password manager that fetches each word from the dictionary server without revealing it, using [single-server private information retrieval](https://en.wikipedia.org/wiki/Private_information_retrieval).
That way, the database server can be fully untrusted! Check it out!
